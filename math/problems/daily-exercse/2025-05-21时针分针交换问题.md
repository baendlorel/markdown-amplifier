# 时针分针交换问题

仙童群

一天所有时刻的表盘（不考虑秒针）中，在交换时针分针位置后仍表示一个正确时刻的表盘有多少个。题设中的时针是实数范围走动的，包含了绝对精确的时间

_proof_

不妨设时间都是 12 小时制，令$t$是精确时间，整小时数为$[t]$，精确分钟数为$t-[t]$。那么时针所在角度就是

$$\theta_h=\frac{t}{12}\cdot2\pi=\frac{\pi t}{6} $$

分针的角度是确定的，为

$$\theta_m=60\cdot(t-[t])\cdot\frac{2\pi}{60}= 2\pi(t-[t])$$

现在交换两者，那么新的精确小时数应该是

$$t^\prime=\theta_m\cdot\frac{12}{2\pi}=2\pi(t-[t])\cdot\frac{12}{2\pi}=12(t-[t])$$

新的精确分钟数是
$$minute=\theta_h\cdot\frac{60}{2\pi}=\frac{\pi t}{6}\cdot\frac{60}{2\pi}=5t$$

要使新的时间成立，那么精确小时数的小数部分应该等于精确分钟数，即要求
$$12(t-[t])-[12(t-[t])]=5t$$

通过画图和验算得知除了 0 外只有一个解为$t=\frac{1}{7}$

```javascript
const f = (x) => 12 * (x - Math.floor(x)) - 12 * Math.floor(x - Math.floor(x)) - 5 * x;
```

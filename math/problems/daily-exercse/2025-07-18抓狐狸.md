# 抓狐狸

五个洞排成一排，其中一个洞里藏有一只狐狸。每个夜晚，狐狸都会跳到一个相邻的洞里。每个白天，你都只允许检查其中一个洞。

怎样才能保证狐狸最终会被抓住？

# 解答

不妨将洞编号为 1、2、3、4、5 号洞。
我们分类讨论狐狸在所有洞里的情况，并且用箭头指示我们的位置。

先考虑简单的情况。

## 只有 2 个洞

狐狸在洞 1

| Day | 洞 1 | 洞 2 |
| --- | ---- | ---- |
| 1   | 狐   | ↑    |
| 2   |      | 狐 ↑ |

第二天抓到

狐狸在洞 2

| Day | 洞 1 | 洞 2 |
| --- | ---- | ---- |
| 1   |      | 狐 ↑ |

**查看策略**：2、2

第一天就抓到

## 有 3 个洞

狐狸在洞 1、3

| Day | 洞 1 | 洞 2    | 洞 3 |
| --- | ---- | ------- | ---- |
| 1   | 狐 A | ↑       | 狐 B |
| 2   |      | ↑ 狐 AB |      |

- 如果狐狸本身就在 2，那么 D1 就抓到了。
- 如果狐狸不在 2, 那么说明在 1 或 3, 第二天一定会跳到 2 号洞，那么 D2 就抓到了。

**查看策略**：2、2

## 有 4 个洞，事情会变得复杂起来

我们需要保持**在每种情况下**，每天选择的洞编号是一样的，题目要求就是要我们“以不变应万变”。

### 情况 1: 狐狸在 2 号洞

D1 选 2 号洞看。

### 情况 2: 狐狸在 1 号洞

| Day | 洞 1 | 洞 2 | 洞 3 | 洞 4 |
| --- | ---- | ---- | ---- | ---- |
| 1   | 狐   | ↑    |      |      |
| 2   |      | 狐 ↑ |      |      |

只需要 D1、D2 都看 2 号洞。

### 情况 3: 狐狸在 3 号洞

第 1 第 2 天必须都看 2 号洞，和情况 1、2 一致

| Day | 洞 1 | 洞 2 | 洞 3 | 洞 4 |
| --- | ---- | ---- | ---- | ---- |
| 1   |      | ↑    | 狐   |      |
| 2   |      | ↑    |      | 狐   |
| 3   |      |      | ↑ 狐 |      |

### 情况 4: 狐狸在 4 号洞

| Day | 洞 1 | 洞 2 | 洞 3 | 洞 4 |
| --- | ---- | ---- | ---- | ---- |
| 1   |      | ↑    |      | 狐   |
| 2   |      | ↑    | 狐   |      |

从第 3 天开始，狐狸可以选择在第 2 天夜晚进入洞 2 或洞 4,因此有了不同分支。

4.1: 狐狸进入洞 4

| Day | 洞 1 | 洞 2 | 洞 3 | 洞 4 |
| --- | ---- | ---- | ---- | ---- |
| 1   |      | ↑    |      | 狐   |
| 2   |      | ↑    | 狐   |      |
| 3   |      |      | ↑    | 狐   |
| 4   |      |      | ↑ 狐 |      |

4 天抓到

4.2: 狐狸进入洞 2

需要保持一致所以第四天必须还看洞 3

| Day | 洞 1 | 洞 2 | 洞 3 | 洞 4 |
| --- | ---- | ---- | ---- | ---- |
| 1   |      | ↑    |      | 狐   |
| 2   |      | ↑    | 狐   |      |
| 3   |      | 狐   | ↑    |      |
| 4   | 狐   |      | ↑    |      |
| 5   |      | 狐 ↑ |      |      |

发现只需要第 5 天看洞 5 即可抓到狐狸

至此 4 个洞的情况完成。
